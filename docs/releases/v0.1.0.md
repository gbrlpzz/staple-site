# Staple public concept record — v0.1.0

**Recorded:** 2026-08-23  
**Repository:** gbrlpzz/staple-site  
**Release:** v0.1.0 public concept record

## What this record documents

This release records the public-facing expression of Staple:

- the Staple name and product framing;
- the landing-page copy and visual design;
- the interface presentation and screenshots;
- a high-level description of the system;
- selected cost, nutrition and waste outcomes.

The public site intentionally excludes the raw benchmark, detailed optimizer logic, full research protocol and private application implementation. Those materials remain in a separate private repository.
