# staple.

Public presentation of **Staple**, a personal nutrition system.

This repository contains the static Vite + React landing site. The page presents the product interface, research framing, frozen pilot results, and an Inquire link.

## Local

```sh
npm install
npm test
npm run dev -- --host 127.0.0.1 --port 4188
```

## Page structure

Hero, then the five product screens (Plan / Choose / Shop / Store / Cook), a guided Research section, compact Results, then Inquire.

Figures are frozen in `src/data/benchmark.json`. Screenshots are real captures in `public/screens/`.
